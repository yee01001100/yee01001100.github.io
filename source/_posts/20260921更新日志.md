# 20260921更新日志

这次把博客从头到尾过了一遍：补齐了一直缺失的导航，处理掉几处藏在元数据里的问题，还修好了代码高亮与 Mermaid 图表。

## 视觉与阅读体验

- **补齐导航栏**：`menu` 配置此前整段处于注释状态，导航栏是空的——分类页和标签页虽然早就建好，却没有任何入口能点进去。现已补上「首页 / 归档 / 分类 / 标签」四项。
- **自制文章封面**：按分类配色手写了 11 张 SVG 封面，首页卡片不再是一整片纯文字。
- **首页头图与打字机副标题**：新增渐变头图，并开启副标题轮播效果。
- **图片灯箱**：启用 fancybox，文章配图点击即可放大查看。
- **细节优化**：开启加载动画与标题图标美化（图标颜色改为主色调蓝），侧边栏补充了公告与作者简介，并启用「站点运行时间」组件。

## 问题修复

- **语法高亮此前完全失效**：`syntax_highlighter` 被设成了 `none`，Hexo 因此不输出任何语法标记，主题也不会生成代码块配色——所有代码块都是一片灰。现已改回 `highlight.js`。
- **代码块改为深色**：`code_blocks.theme` 由 `light` 改为 `darker`，现在是深色底 + 彩色高亮 + 行号。
- **Mermaid 图表可以正常渲染了**：开启高亮之后，mermaid 代码块会被 Hexo 当作普通代码块处理，主题找不到渲染目标。新增前置过滤器 `scripts/mermaid-codeblock.js` 解决，现在照常写 mermaid 代码块即可出图。
- **front-matter 数据修正**：
  - 修正 openEuler 篇的非法日期格式（`2026-09-09-27`）
  - 修正 `-Linux`、`-sql` 两处因缺少空格而产生的错误标签名
  - 统一分类与标签的大小写（`sql`/`SQL`、`JAVA`/`Java`、`web`/`Web`），消除重复的分类页与标签页
  - 4 处图片相对路径改为绝对路径
  - 删除两篇文章正文开头多余的 `---` 分隔线
- **分享按钮精简**：仅保留微信与 QQ，去掉 X、Facebook、微博。
- **站点图标修正**：原先指向不存在的文件，改为主题自带的图标。

## 仓库整理

- 清理了 19 个被误提交到 `source` 分支的生成产物（根目录下的 `index.html`、`css/`、`js/`、`img/`、`archives/`、`2026/`），`.gitignore` 已补上对应规则，避免再次误提交。
- README 更正了三处与实际情况不符的说明：补充 `source` / `main` 双分支说明、把「主题特性」改成「主题支持 vs 实际启用」对照表、部署流程改为真实的本地手动部署。
